# Статьи блога

Один файл = одна статья: `articles/<slug>.md`.

Жизненный цикл поля `status`:

| status | что происходит |
|---|---|
| `draft` | черновик. Уходит клиенту на согласование в Telegram, страница-предпросмотр закрыта от индексации |
| `approved` | клиент нажал «Опубликовать». Сборщик сам назначает дату выхода (по умолчанию раз в 7 дней) |
| `published` | статья на сайте, в sitemap и RSS. Ставится автоматически, когда наступила дата |

Руками менять `date`, `notified` и `status: published` не нужно. Для `draft` достаточно положить файл сюда и сделать `git push`.
