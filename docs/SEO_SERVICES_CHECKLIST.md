# Куда добавлять сайт клиента, чтобы он ранжировался

Делается один раз при запуске сайта. Отмечай галочки в карточке клиента.
Условные обозначения: **[обяз.]** — всем, **[лок.]** — если у клиента есть город/офис/выезд, **[ниша]** — по тематике.

## 0. Перед всем остальным

- [ ] **Свой домен** [обяз.]. Сайт на `*.github.io` живёт на общем домене без истории, поэтому в поиске ранжируется заметно слабее. Тестировать можно на github.io, а для SEO-клиента нужен домен (как у dalihome). Без домена SEO-обещания клиенту не даём.
- [ ] В `blog.config.json` в `siteUrl` прописан финальный домен, в репозитории есть `CNAME`. После смены домена перезапусти сборку: sitemap и canonical обновятся сами.
- [ ] HTTPS включён (галка «Enforce HTTPS» в настройках Pages).

## 1. Вебмастера (индексация) [обяз.]

| Сервис | Что сделать |
|---|---|
| **Яндекс Вебмастер** (webmaster.yandex.ru) | Добавить сайт → подтвердить права (мета-тег или файл в корне) → «Индексирование → Файлы Sitemap» добавить `/sitemap.xml` → «Региональность» указать город → проверить, что нет ошибок robots. Именно отсюда идёт основной трафик в РФ |
| **Google Search Console** | Добавить ресурс → подтвердить → Sitemaps → отправить `/sitemap.xml` |
| **Bing Webmaster Tools** | «Импорт из GSC» одной кнопкой. Даёт IndexNow и заодно часть нейро-поисковиков |
| **Яндекс Метрика** | Уже ставим. Проверить, что цель «Заявка» настроена: без неё нельзя понять, какие статьи приводят клиентов |

**IndexNow** работает автоматически: при выходе статьи Action пингует Яндекс и Bing (ключ создаётся в `blog.config.json`). В Вебмастере он виден в разделе «Переобход страниц».

## 2. Карты и локальная выдача [лок.]

- [ ] **Яндекс Бизнес** (карточка организации). Даёт показ в Яндекс Картах и в блоке организаций в поиске. Нужны: адрес или зона обслуживания, телефон, часы, фото, ссылка на сайт.
- [ ] **2ГИС**: карточка с той же информацией.
- [ ] **Google Business Profile**.
- Во всех карточках название, адрес и телефон должны совпадать буква в букву с сайтом. Разнобой снижает доверие.

## 3. Профили с ссылкой на сайт (доверие и ссылочный вес) [обяз.]

- [ ] **Telegram-канал** клиента, ссылка на сайт в шапке и в закрепе.
- [ ] **VK-сообщество** (ссылка в разделе «Сайт»).
- [ ] **Яндекс Дзен-канал** (ссылка на сайт в описании; статьи → см. раздел 5).
- [ ] **vc.ru** профиль эксперта или компании.
- [ ] Свои соцсети (Instagram/YouTube) — ссылка на сайт в био, если ведёт клиент.

## 4. Площадки-каталоги по нишам [ниша]

| Ниша | Где завести профиль |
|---|---|
| Юристы | Pravoved, Профи.ру, Яндекс Услуги, Право.ру |
| Психологи, коучи, эзотерика | Профи.ру, Яндекс Услуги, b17 (психологи), Авито Услуги |
| Недвижимость, ипотека | Циан / Авито / Домклик (профиль риелтора), Яндекс Недвижимость |
| Дизайн интерьера, ремонт, мебель | Профи.ру, Houzz, Авито Услуги, Pinterest, Яндекс Услуги |
| Маркетологи, агентства | vc.ru, Рейтинг Рунета, Tagline |
| Любые локальные услуги | Zoon, Flamp, Отзовик, Авито |

Правило: **1–2 профиля на клиента и с реальным описанием**, а не 30 каталогов. Массовая регистрация в каталогах в 2026 году больше вредит, чем помогает.

## 5. Где публиковать статьи (выбор площадок)

Из всех площадок оставляем две, остальные не ведём:

| Площадка | Для каких ниш | Почему |
|---|---|---|
| **Яндекс Дзен** | все B2C-ниши: юристы, психологи, астрологи, дизайнеры, риелторы, коучи, услуги для физлиц | Самая большая аудитория «читателей по интересам», статьи попадают и в Яндекс-поиск. Главный источник тёплого трафика |
| **vc.ru** | B2B и эксперты для предпринимателей: маркетинг, юрфирмы для бизнеса, бухгалтерия, агентства, IT | Деловая аудитория, высокий вес домена, статьи хорошо индексируются |

Правила те же для обеих:
- Статья сначала выходит на сайте. Через 2–3 дня, когда она в индексе, выходит **отдельно написанная** адаптация (режим DZEN / VC в `SEO_ARTICLE_PROMPT.md`) со ссылкой на источник.
- Ссылки оттуда обычно с `nofollow`: вес в SEO они не передают. Их ценность в трафике, узнаваемости и доверии.
- Публикация вручную из кабинета: у Дзена нет открытого API для новых статей, а автоматизацию vc.ru лучше не подключать (риск блокировки).

## 5.1. Автоматическая индексация сайтов клиентов

- **Автоматически (без участия менеджера):** при выходе каждой статьи сайт сам отправляет её в Яндекс и Bing (IndexNow). Плюс обновляется `sitemap.xml` и RSS.
- **Одной кнопкой из кабинета:** «Отправить сайт в индекс» (`POST /seo/index` в Worker) отправляет все страницы сайта в Яндекс и Bing. Ставить после подключения сайта.
- **Google:** аналога IndexNow нет. Один раз на клиента добавить сайт в Search Console и подать `sitemap.xml` (раздел 1).
- Автодобавление сайтов в Яндекс Вебмастер возможно только через их API с токеном владельца аккаунта. Пока делаем вручную по чек-листу.

## 6. Технический минимум на самом сайте (шаблон уже делает сам)

- [x] `sitemap.xml`, `robots.txt`, `feed.xml` (обновляются при каждой публикации)
- [x] canonical, Open Graph, заголовок и описание на каждой статье
- [x] Разметка Schema.org: `Article`, `BreadcrumbList`, `FAQPage`
- [x] Внутренняя перелинковка: «Читайте также», блок статей на главной, ссылка в меню
- [ ] **Вручную:** alt у фото, быстрые фото (сжимать до 200–300 КБ), уникальный `title` и `description` у главной

## 7. Через 2–4 недели после старта

- Вебмастер → «Индексирование → Страницы в поиске»: все ли статьи проиндексированы.
- Если статья не в индексе через 7 дней: «Переобход страниц» → отправить вручную.
- Метрика → «Источники → Поисковые системы»: первые визиты идут обычно через 3–6 недель, топ-10 по средним запросам через 2–4 месяца при регулярной публикации.
